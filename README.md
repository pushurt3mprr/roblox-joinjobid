# roblox-joinjobid

based off of https://github.com/DaRealRomz/roblox-jobid-join

## what is this?

this is a simple userscript that allows you to join specific jobids from a gui in the server list.

## how do i install it?

1. get any userscript manager (i recommend [tampermonkey](https://www.tampermonkey.net/index.php) personally)
2. click [this link](https://github.com/pushurt3mprr/roblox-joinjobid/raw/refs/heads/main/roblox_jobid_join.user.js) which should install it automatically
3. profit??
